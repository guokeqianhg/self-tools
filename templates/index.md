# 文档模板

管理台可根据模板自动生成填写表单；`template_name` 和 `template_desc` 只用于展示，不会写入正式文档。

| 模板 | 用途 | 默认知识域 |
|---|---|---|
| [指标定义](metric.md) | 指标、口径与基线 | `metrics/` |
| [功能说明](feature.md) | 系统、功能或工具说明 | `product/` |
| [接口/工具文档](api-endpoint.md) | 接口或工具使用说明 | `product/` |
| [问题排查记录](case-record.md) | 现象、分析与处理记录 | `guides/` |
| [流程 SOP](sop.md) | 标准操作流程 | `guides/` |
| [测试报告](test-report.md) | 测试范围、结果与结论 | `guides/` |
| [会议纪要](meeting-notes.md) | 讨论、决策和待办 | `guides/` |
| [决策记录](decision.md) | 决策背景与结论 | `team/` |
| [外部资料笔记](reference-note.md) | 公开资料的阅读笔记 | `references/` |
