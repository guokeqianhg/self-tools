# 新建知识

1. 确认资料可公开使用或已取得共享授权。
2. 选择合适的知识域，填写标题、摘要和来源。
3. 使用管理台的描述生成、上传整理或模板填空创建草稿。

# 审核与发布

1. 校对事实、链接、引用和敏感信息。
2. 草稿使用 `review`；需要复核的旧内容使用 `verify`；确认可用后设置为 `ready`。
3. 发布后检查索引和检索结果是否正常。

# 定期维护

- 定期处理知识缺口和断链；
- 对长期未更新的文档进行复审；
- 删除过期、重复或未获授权的资料；
- 变更术语或目录结构前，先更新 [填写规范](/CONTRIBUTING.md)。
