# 术语表

| 术语 | 说明 |
|---|---|
| 知识域 | 按内容用途划分的一级目录。 |
| 文档状态 | `ready`、`review`、`verify` 三种审核状态。 |
| 责任人 | 负责确认或更新文档的角色或人员。 |
| 引用 | 文档末尾 `# Citations` 中登记的外部来源。 |
| 知识缺口 | 问答未命中、尚需补充的主题。 |
